Pleiades Reference Lookup

Type a toponym to look it up in the Pleiades gazetteer: the last word you type is matched as a prefix. Pick a scope to limit the search, click the options button to set all the other filters (including spatial ones drawn on a map), or click the More button to open the full search in a dialog. This requires the Pleiades API (see pleiadesUrl in env.js).

In the options, the save button stores the filters in your browser: the lookup then uses them whenever it has no options, e.g. when you come back to this page.
